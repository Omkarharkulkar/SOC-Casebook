## Scenario context available before analysis
The publisher describes this as a synthetic, vendor-generated,
post-compromise network scenario. Initial-access traffic is not included.
Routine network traffic and multiple scenario-driven interactions occur
over the capture period. The scenario is intended for independent
analysis of relationships, timing, and network activity.

This context is publisher-provided information and is not independently
verified by this investigation.

## Intended analysis
- Identify participating hosts and their apparent network roles.
- Review protocol and conversation distributions.
- Reconstruct relevant communication sequences and timelines.
- Examine DNS queries, responses, query types, and name characteristics.
- Review HTTP metadata and TLS SNI where observable.
- Compare SNI with destinations and connection context.
- Review SMB session metadata only; do not extract file content.
- Examine NTP behavior and timing relationships.
- Identify observations that may support detection hypotheses.
- Compare observed DNS and network patterns with the Part A baseline,
  where the comparison is meaningful.

IOC enrichment is not planned because the dataset is synthetic and its
infrastructure is not expected to represent real-world indicators.

## Handling plan
- Analyze within the Ubuntu lab VM.
- Keep the original PCAP local and excluded from Git.
- Verify the downloaded file against the publisher's checksum.
- Record the locally calculated SHA-256 and comparison result.
- Do not execute extracted files or visit URLs found in the capture.
- Do not export payload contents.
- SMB analysis will be limited to session and metadata observations.
- Publish only derived observations, defanged indicators, and original
  analysis/documentation.

## Blind-analysis method
Complete the investigation and assessment using the PCAP and the limited
scenario context above. Do not consult supplementary scenario answers
before documenting findings.

No ground-truth comparison is planned because no answer key is public.
Verdicts will be expressed as hypotheses with confidence and limitations.
ATT&CK mappings, if included, will be labelled candidate techniques
and tied to specific evidence.
