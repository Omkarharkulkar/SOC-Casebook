## 1. Case Summary

This investigation analyzed a network capture containing DNS, HTTP, TLS, SMB2 and DCE/RPC traffic.

The capture initially showed routine Windows connectivity and update-related traffic. Further investigation identified repeated SMB file operations and remote Service Control Manager (SCM) activity originating from HOST-1 (`10.42.10.21`).

The investigation identified two correlated service-control waves involving the same six destination systems. During the first wave, a service named `WinHostSvc` was created using a command-interpreter binary path. During the second wave, a service named `WinUpdateSvc` was created using a binary located in the Windows Temp directory.

The service-creation operations returned successful responses in both waves. The first wave's service-start operations returned request-timeout errors, while the second wave's service-start operations returned successful responses.

SMB traffic also showed repeated CREATE and WRITE operations involving `q4-summary.bin` over the `ADMIN$` share. All 11 observed WRITE requests were 96 bytes and received successful SMB responses.

The combination of repeated file operations, remote service creation, service-start requests, multiple destinations and closely grouped timing is suspicious and consistent with coordinated remote activity.

However, this investigation was performed using network evidence only. The capture does not independently establish authorization, successful endpoint execution, persistence, operator identity or confirmed compromise.

**Final assessment:** Suspicious remote service execution and lateral movement observed — escalate to L2 for validation.

## 6. SMB2 Analysis

### 6.1 Shares observed

The following SMB shares were identified:

- `\\files.arden.local\ADMIN$`
- `\\files.arden.local\IPC$`

No `C$` share was observed in the analyzed traffic.

The `ADMIN$` share is an administrative share commonly used for Windows administration. Its use is not inherently malicious; context and associated activity are important.

### 6.2 Repeated file operations

The investigation identified 11 SMB CREATE requests involving:

`q4-summary.bin`

All requests originated from HOST-1:

`10.42.10.21`

The CREATE requests used command 5 and disposition 1, corresponding to `FILE_OPEN`.

This indicates that the requests were attempting to open an existing file rather than create a new file.

The CREATE requests were associated with the `ADMIN$` share through their Tree Connect relationships.

### 7.2 Correlated SCM sequences

The SCM operations CSV and decoded packet details establish two repeated service-control waves initiated by HOST-1 (`10.42.10.21`).

Each wave covered the same six destinations:

- HOST-2 (`10.42.10.22`)
- `10.42.20.40`
- `10.42.20.30`
- `10.42.20.10`
- `10.42.20.15`
- `10.42.20.20`

1. `ROpenSCManagerW` — opnum 15, call ID 2
2. `RCreateServiceW` — opnum 12, call ID 3
3. `RStartServiceW` — opnum 19, call ID 4

Each request and corresponding response was correlated using its TCP stream and DCE/RPC call ID.

This establishes 12 complete SCM sequences across the two waves.

### 7.5 SCM activity assessment

The repeated operation order, six-host scope, tightly grouped packet timing and recurrence approximately four minutes apart support an inference of coordinated or automated remote service-control activity.

The first wave involved a command-interpreter service path. The second involved an executable located in the Windows Temp directory.

The activity is suspicious and warrants endpoint validation.

However, network evidence alone does not establish:

- Whether the commands successfully executed.
- Whether the service binaries were malicious.
- Whether the activity was authorized.
- Whether the systems were compromised.
- Whether the services remained installed.
- Whether the activity resulted in persistence.

### 7.6 Correlated Multi-Host Activity

The investigation identified a repeated sequence of internal SMB and SCM activity involving the same group of destinations.

The observed stages included:

1. Named-pipe activity involving `srvsvc`.
2. SCM manager-open operations.
3. SMB CREATE and WRITE operations involving `q4-summary.bin`.
4. Additional `srvsvc` and `samr` activity.
5. Further SCM manager access.
6. Remote service creation and start requests.
7. A second file-operation burst.
8. A second service-control wave.

The sequence and timing are consistent with coordinated remote activity across multiple hosts.

The exact purpose of the earlier `srvsvc` and `samr` operations was not established because their specific operation numbers were not confirmed. They are treated as enumeration-consistent observations with low confidence.

## 10. Detection Hypotheses

The following detection hypotheses could be developed from the observed behavior.

### Hypothesis 1 — Multi-host SMB file activity

Alert when one source accesses administrative shares on multiple hosts within a short period and performs repeated file operations.

Potential conditions:

- Multiple internal destinations.
- Administrative share access.
- Repeated file CREATE/WRITE operations.
- Similar filenames or file-operation patterns.
- Repeated bursts from the same source.

### Hypothesis 2 — Remote service creation

Alert when a source system creates services on multiple destination systems within a short time window.

Potential conditions:

- `RCreateServiceW` observed.
- Multiple destination hosts.
- Repeated service names.
- Service binary paths containing suspicious locations or command interpreters.
- Subsequent `RStartServiceW` requests.

### Hypothesis 3 — Service creation followed by start

Correlate service creation and service-start requests using destination, TCP stream and DCE/RPC call information.

Raise investigation priority when the sequence repeats across several hosts.

### Hypothesis 4 — Coordinated multi-host activity

Detect repeated patterns involving:

- SMB administrative share activity.
- Remote service-control operations.
- Multiple destination hosts.
- Similar operation ordering.
- Closely grouped timestamps.
- Repeated activity waves.

The observed CASE-005 traffic would be a useful dataset for testing these hypotheses in a future SIEM or MiniSOC detection workflow.

These are detection hypotheses and have not been implemented or tested against a production environment.

## 14. Final Conclusion

The network capture contains suspicious SMB file operations and repeated remote Service Control Manager activity originating from HOST-1 (`10.42.10.21`).

The investigation identified 11 SMB CREATE requests and 11 corresponding WRITE requests involving `q4-summary.bin`. Each WRITE was 96 bytes, and all 11 SMB WRITE responses returned success.

Two complete SCM waves were observed across six destinations. Both waves used the same operation sequence: manager open, service creation and service start.

During the first wave, `WinHostSvc` was created with a command-interpreter binary path. All six service-creation responses were successful, while all six service-start responses returned a request timeout.

During the second wave, `WinUpdateSvc` was created using a binary path located in the Windows Temp directory. All six service-creation and service-start responses returned success.

The repeated operation sequence, multiple destinations, closely grouped timing and recurrence support an inference of coordinated remote activity.

**Final verdict: Suspicious remote service execution and lateral movement observed — escalate to L2 for validation.**

The investigation does not establish confirmed compromise, successful endpoint execution, persistence, operator identity or malicious intent.

Further investigation should prioritize endpoint telemetry from all six destinations, verification of the service binaries, service installation and execution records, file activity, account attribution and authorization records.
