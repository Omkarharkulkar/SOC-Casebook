## Intended analysis
- Identify participating hosts and their apparent network roles.
- Review protocol and conversation distributions.
- Reconstruct relevant communication sequences and timelines.
- Examine DNS queries, responses, query types, and name characteristics.
- Review HTTP metadata and TLS SNI where observable.
- Compare SNI with destinations and connection context.
- Review SMB session metadata only; do not extract file content.
- Examine NTP behavior and timing relationships.
- Identify observations that may support detection hypotheses.
- Compare observed DNS and network patterns with the Part A baseline,
  where the comparison is meaningful.

IOC enrichment was not performed because the dataset is synthetic and
its infrastructure is not expected to represent real-world indicators.
